# USB Volume 0.3.0

A compact mixer for USB speakers: master volume, independent app volume, and a companion extension for browser tabs.

## Highlights

- Per-app volume and mute with remembered settings; master and app levels combine.
- Chrome / Edge 116+ companion for separate tab volume, included in the app and downloadable separately.
- A refined 300 px native panel, light/dark appearance, and subtle motion with immediate keyboard/Reduce Motion behavior.
- 14 languages across the app, extension, and website, including Arabic RTL and localized percentages.
- Safer audio routing during temporary CoreAudio discovery failures and muted-route recovery.
- New website, illustrated English/Chinese README, and contribution guide.

## Download

- **USBVolume-0.3.0-arm64.zip** — macOS app, for Apple Silicon and macOS 14.2+.
- **USBVolume-BrowserExtension-0.3.0.zip** — unpacked Chrome / Edge extension.
- **SHA256SUMS.txt** — SHA-256 checksums for both archives.

Move the app to Applications and allow system audio recording when prompted. The app is locally signed and **not notarized by Apple**. If macOS blocks opening, use System Settings → Privacy & Security → Open Anyway. Keyboard volume keys separately require Accessibility permission.

Load the extension unpacked through Chrome / Edge's extensions page in Developer mode. Tab controls live in its popup, not the native panel; tab settings do not persist after a browser restart.

Designed for stereo USB outputs without input channels. Compatibility varies by hardware and media. **Pause playback before quitting or stopping control**, as the speaker returns to its original volume.
